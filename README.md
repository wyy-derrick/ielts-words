# 雅思背词 — 错词表 + 538 考点词 + 听力听写 + d词表

纯前端背词工具，一个页面包含五个词库，托管在 GitHub Pages，
电脑 / iPad / 手机浏览器打开即用，无需服务器。

在线访问：`https://wyy-derrick.github.io/ielts-words/`

## 功能

- **词库切换**
  - **错词表**：阅读/听力复盘错词，所有单词在一起，每满 100 词自动成一组
  - **538 考点词**：刘洪波考点词 378 个（固定词库，不再更新），保留原三组分类
  - **听力听写**：播放英音后输入拼写
  - **d阅读错词**：独立板块，题型和错词表一样（看英文选中文）
  - **d听力单词**：独立板块，题型和听力听写一样（听英音拼写）
- **题型自动适配**：错词表 / d阅读错词选中文释义；538 考点词选同义替换；听力听写 / d听力单词听音拼写
- **答案卡**：释义 / 全部同义词 / 中文 / 雅思命题说明 / 记录来源 / 例句，有啥显示啥
- **背诵模式**：选择题显示单词后 4 选 1；听写先播英音再输入拼写，然后出答案卡
- **测试模式**：整组乱序测试 → 成绩单 + 错题本，支持"只测错题"重测
- **搜索**：按单词、中文、同义词搜全部词条
- **进度记忆**：背诵位置和错题次数保存在浏览器本地，五个词库进度独立；不同设备各自独立

## 两套本地环境（Excel 不上传）

本仓库在两套本地环境使用，网页是同一份 GitHub Pages。
各环境只维护自己的 Excel，文件都在 `.gitignore` 里，不会进 Git。
运行 `更新词库.py` 后，单词写入 `data.js` 再推送，网页即可更新。

| 环境 | 本地 Excel | 写入网页的板块 |
| --- | --- | --- |
| A 笔记库 | `plan/雅思错词表.xlsx`（相对本仓库为 `../plan/`，或 `~/wyy_notes/知识库/08-个人发展/英语/plan/`） | **错词表**、**听力听写** |
| B 本仓库目录 | `d词表.xlsx` | **d阅读错词**、**d听力单词** |

538 考点词两边共用，来源是仓库里的 `词库538.json`，不随 Excel 更新。

某环境缺少另一份 Excel 时，脚本会保留 `data.js` 里已有的对应板块，不会把另一边的词库清空。
更新前请先 `git pull`，避免两边各改 `data.js` 时互相覆盖。

## 日常更新词库

在**有新词的那套环境**里操作：

```bash
git pull
python 更新词库.py
git add -A
git commit -m "更新词库"
git push
```

环境 A 的脚本也可写成：

```bash
/home/wyy/anaconda3/bin/python 更新词库.py
```

脚本读取 xlsx 中所有「错词表」工作表（阅读 + 听力），同一单词重复记错只保留
最早一条；已有单词的编号和顺序保持不变，新词自动追加在末尾。
正常只在末尾追加不影响浏览器里存的进度；若在中间删改行，进度可能轻微错位。

### 环境 B：d词表.xlsx

```
阅读单词 | 阅读中文 | 听力单词 | 听力中文
```

- 阅读列 → 前端「d阅读错词」，必须填中文才能出选择题
- 听力列 → 前端「d听力单词」，可以只填单词
- 不会并进「错词表」或「听力听写」
- 本文件只留在本地，不上传 GitHub

## 首次部署（GitHub Pages）

1. 在 GitHub 新建一个仓库（Public），不要勾选初始化 README
2. 本目录已 git init 并完成首次提交，只需关联远程并推送：
   ```bash
   git remote add origin git@github.com:<你的用户名>/<仓库名>.git
   git push -u origin main
   ```
3. 仓库页面 → Settings → Pages → Source 选 **Deploy from a branch**，
   Branch 选 **main** / **root**，Save
4. 等 1–2 分钟部署完成，用上面的网址访问
5. iPad：Safari 打开网址 → 分享 → **添加到主屏幕**，即可以 App 形式全屏使用

## 文件说明

```
├── index.html    # 主程序（界面 + 逻辑，唯一入口）
├── data.js       # 词库数据（更新词库.py 自动生成，勿手改）

├── 更新词库.py    # 两套本地 Excel + 词库538.json → data.js
├── d词表.xlsx     # 环境 B 源表（gitignore，不上传）
├── .gitignore
└── README.md
```

更新词库.py 运行依赖 openpyxl。环境 A 若移动了本文件夹，
脚本会自动按 `~/wyy_notes/知识库/08-个人发展/英语/plan/` 兜底寻找错词表 xlsx。
