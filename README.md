# Derrick 的 IELTS 备考站

Derrick 的个人雅思备考网站，采用纯前端静态页面，托管在 GitHub Pages。
打开网站首页后，可以自主选择 **单词**、**作文** 或 **口语** 模块；三个模块分别使用独立页面，电脑、iPad、手机浏览器均可直接打开，无需服务器。

在线访问：`https://wyy-derrick.github.io/ielts-words/`

## 页面结构

- **首页**：模块选择入口，不加载具体学习数据
- **单词模块**：`words.html`，目前已完成
- **作文模块**：`writing.html`，页面已建立，内容待整理
- **口语模块**：`speaking.html`，语言习惯、P1 / P2 / P3 资料与考场演练

首页只负责选择模块。进入单词模块后，才会加载 `data.js` 和完整的单词学习功能。

## 单词模块功能

- **词库切换**
  - **错词表**：阅读/听力复盘错词，所有单词在一起，每满 100 词自动成一组
  - **538 考点词**：刘洪波考点词 378 个（固定词库，不再更新），保留原三组分类
  - **听力听写**：播放英音后输入拼写
  - **d阅读错词**：独立板块，题型和错词表一样（看英文选中文）
  - **d听力单词**：独立板块，题型和听力听写一样（听英音拼写）
- **题型自动适配**：错词表 / d阅读错词选中文释义；538 考点词选同义替换；听力听写 / d听力单词听音拼写
- **答案卡**：释义 / 全部同义词 / 中文 / 雅思命题说明 / 记录来源 / 例句，有啥显示啥
- **背诵模式**：选择题显示单词后 4 选 1；听写先播英音再输入拼写，然后出答案卡
- **测试模式**：整组乱序测试 → 成绩单 + 错题本，支持“只测错题”重测
- **搜索**：按单词、中文、同义词搜全部词条
- **进度记忆**：背诵位置和错题次数保存在浏览器本地，五个词库进度独立；不同设备各自独立

## 两套本地环境（Excel 不上传）

本仓库在两套本地环境使用，网页是同一份 GitHub Pages。
各环境只维护自己的 Excel，文件都在 `.gitignore` 里，不会进 Git。
运行 `更新词库.py` 后，单词写入 `data.js`，再推送即可更新网页中的单词模块。

| 环境 | 本地 Excel | 写入网页的板块 |
| --- | --- | --- |
| A 笔记库 | `plan/雅思错词表.xlsx`（相对本仓库为 `../plan/`，或 `~/wyy_notes/知识库/08-个人发展/英语/plan/`） | **错词表**、**听力听写** |
| B 本仓库目录 | `d词表.xlsx` | **d阅读错词**、**d听力单词** |

538 考点词两边共用，来源是仓库里的 `词库538.json`，不随 Excel 更新。

某环境缺少另一份 Excel 时，脚本会保留 `data.js` 里已有的对应板块，不会把另一边的词库清空。
更新前请先 `git pull`，避免两边各改 `data.js` 时互相覆盖。

## 日常更新词库

在**有新词的那套环境**里操作：

```bash
git pull
python 更新词库.py
git add -A
git commit -m "更新词库"
git push
```

环境 A 的脚本也可写成：

```bash
/home/wyy/anaconda3/bin/python 更新词库.py
```

脚本读取 xlsx 中所有「错词表」工作表（阅读 + 听力），同一单词重复记错只保留最早一条；已有单词的编号和顺序保持不变，新词自动追加在末尾。
正常只在末尾追加不影响浏览器里存的进度；若在中间删改行，进度可能轻微错位。

### 环境 B：d词表.xlsx

```
阅读单词 | 阅读中文 | 听力单词 | 听力中文
```

- 阅读列 → 前端「d阅读错词」，必须填中文才能出选择题
- 听力列 → 前端「d听力单词」，可以只填单词
- 不会并进「错词表」或「听力听写」
- 本文件只留在本地，不上传 GitHub

## 口语模块

- **资料卡片**：语言习惯、评分要求、P1 人设语料、P2 三个万能剧本与 P3 追问展开方式，存于 `speaking-data.js`
- **考场演练**（题目数据来自 `speaking-questions.js`，只收录大陆题）：
  - **P1 抽题**：大陆话题随机抽，小问逐题过
  - **P2 计时 + P3 追问**：1 分钟准备 + 2 分钟作答倒计时（最后 10 秒变红、结束提示音），作答完接着过本题的 P3 抽象追问
  - **全套模拟**：P1 两个话题 → P2 → 同题 P3 完整流程，带总计时
- **优先抽新题**：默认开启，新题抽完才轮到保留题 / 万年老题；关闭则全池混抽
- **已练沉底**：练过的题自动排到没练过的后面，进度存浏览器 localStorage；演练页可一键「清除练习记录」（保留开关偏好）
- **剧本提示**：P2 题卡下方提示这道题建议套哪个万能剧本

### 口语题库更新流程

```
雅思哥题库 PDF（本地文件，不上传）
  → 解析题库PDF.py  →  口语题库.xlsx（可手工编辑：地区 / 状态 / 剧本列）
  → 更新口语题库.py  →  speaking-questions.js（进 git，网页使用）
```

- 换季新 PDF：放本目录后重跑两个脚本；xlsx 里人工填的「剧本」列会按题名保留
- 季度内改题 / 加题：直接编辑 `口语题库.xlsx`，再跑 `更新口语题库.py`
- 「地区」填非大陆的题不会进网页；「状态」（新题 / 保留题 / 万年老题）驱动优先抽新题

## 首次部署（GitHub Pages）

1. 在 GitHub 新建一个仓库（Public），不要勾选初始化 README
2. 本目录已 git init 并完成首次提交，只需关联远程并推送：
   ```bash
   git remote add origin git@github.com:<你的用户名>/<仓库名>.git
   git push -u origin main
   ```
3. 仓库页面 → Settings → Pages → Source 选 **Deploy from a branch**，Branch 选 **main** / **root**，Save
4. 等 1–2 分钟部署完成，访问网站根地址；首页会先显示三个学习模块
5. iPad：Safari 打开网址 → 分享 → **添加到主屏幕**，即可以 App 形式全屏使用

```
├── data.js          # 单词数据（更新词库.py 自动生成，勿手改）
├── 词库538.json     # 538 考点词源数据（固定，不更新）

├── 口语题库.xlsx    # 口语题库源表（gitignore，不上传，可手工编辑）

```

更新词库.py 运行依赖 openpyxl。环境 A 若移动了本文件夹，脚本会自动按 `~/wyy_notes/知识库/08-个人发展/英语/plan/` 兜底寻找错词表 xlsx。

## 技术

纯前端，零依赖。首页和三个模块页面均为静态 HTML；单词数据通过 `<script>` 标签加载，无需构建和服务器。
