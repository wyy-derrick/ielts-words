# 雅思背词 — 错词表 + 538 考点词

纯前端背词工具，一个页面包含两个词库，托管在 GitHub Pages，
电脑 / iPad / 手机浏览器打开即用，无需服务器。

在线访问：`https://<你的用户名>.github.io/<仓库名>/`

## 功能

- **双词库切换**
  - **错词表**：阅读/听力复盘错词（来自 `../plan/雅思错词表.xlsx`，会持续更新），所有单词在一起，每满 100 词自动成一组
  - **538 考点词**：刘洪波考点词 378 个（固定词库，不再更新），保留原三组分类
- **两种题型自动适配**：错词表选中文释义；538 考点词选同义替换
- **答案卡**：释义 / 全部同义词 / 中文 / 雅思命题说明 / 记录来源 / 例句，有啥显示啥
- **背诵模式**：显示单词 → 4 选 1 → 出答案卡
- **测试模式**：整组乱序测试 → 成绩单 + 错题本，支持"只测错题"重测
- **搜索**：按单词、中文、同义词搜全部词条
- **进度记忆**：背诵位置和错题次数保存在浏览器本地，两个词库进度独立；不同设备各自独立

## 日常更新词库（错词表有新词时）

```bash
# 1. xlsx 有新错词后（由 plan/生成雅思错词表.py 维护），在本目录运行：
/home/wyy/anaconda3/bin/python 更新词库.py

# 2. 推送，GitHub Pages 自动更新：
git add -A
git commit -m "更新词库"
git push
```

脚本读取 xlsx 中所有"错词表"工作表（阅读 + 听力），同一单词重复记错只保留
最早一条；已有单词的编号和顺序保持不变，新词自动追加在末尾。
正常只在末尾追加不影响浏览器里存的进度；若在中间删改行，进度可能轻微错位。

## 首次部署（GitHub Pages）

1. 在 GitHub 新建一个仓库（Public），不要勾选初始化 README
2. 本目录已 git init 并完成首次提交，只需关联远程并推送：
   ```bash
   git remote add origin git@github.com:<你的用户名>/<仓库名>.git
   git push -u origin main
   ```
3. 仓库页面 → Settings → Pages → Source 选 **Deploy from a branch**，
   Branch 选 **main** / **root**，Save
4. 等 1–2 分钟部署完成，用上面的网址访问
5. iPad：Safari 打开网址 → 分享 → **添加到主屏幕**，即可以 App 形式全屏使用

## 文件说明


脚本会自动按 `~/wyy_notes/知识库/08-个人发展/英语/plan/` 兜底寻找 xlsx。
